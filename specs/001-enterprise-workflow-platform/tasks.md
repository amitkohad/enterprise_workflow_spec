# Platform Task Index

This parent backlog is superseded by the micro-level feature packages in
[roadmap.md](roadmap.md). Execute F01 through F16, and each feature's T001 onward,
in dependency order. Identify tasks as `Fxx/Txxx`; local task numbers may repeat.

Every feature has its own `spec.md`, corresponding `plan.md` and `tasks.md`.
Each yields a complete version of the same image with role configuration,
an executable smoke checkpoint, acceptance evidence and rollback conditions.

The earlier [80-task reference](task-reference.md) is retained for provenance
and requirement mapping only. Do not feed it to an implementation agent.
No task has been implemented in this specification repository.

Start with [F01 tasks](../002-role-runtime-health/tasks.md) and
[AI handoff](ai-handoff.md). Feature-local acceptance closes a task;
complete V-001–V-030 gates and parent SC criteria close production readiness.
